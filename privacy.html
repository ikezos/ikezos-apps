プライバシーポリシー

このアプリは、運営者本人のGoogleアカウントのデータ(Gmail・カレンダー)を、本人の端末上での自動化のためにだけ読み書きします。

  • データを第三者に提供・販売しません。広告には使いません。
  • データの保存は、本人が管理する機器の中に限ります。
  • アクセスは、Googleアカウントの設定(サードパーティのアクセス)からいつでも取り消せます。

Google API から受け取った情報の利用は、Google API Services User Data Policy(Limited Use の要件を含む)に従います。

お問い合わせ: GitHub

Privacy Policy (English)

This app reads and writes the operator's own Google account data (Gmail, Calendar) solely for personal automation on the operator's own devices.

  • Data is never shared with or sold to third parties, and is not used for advertising.
  • Data is stored only on devices managed by the operator.
  • Access can be revoked at any time from Google Account third-party access.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
